## 一、功能概述

「实时监测分析」用于查看现场仪表当前读数、在工艺/配电系统图上叠加实时值，并辅助判断采集网关与计量器具连通情况。

| 子功能 | 典型菜单名称 | 主要用途 |
|--------|--------------|----------|
| 能源实时监测 | 实时监测 | 按用能单元与能源类型查看设备测点实时值，并可打开历史曲线 |
| 组态图监测 | 电力组态图监测 / 用水组态图监测 等 | 在 SVG 系统图上绑定指标，定时刷新实时值 |
| 网关状态监测 | 网关状态监测 | 网关与计量器具连通态势示意（见第六节说明） |
| 网关台账 | 网关台账（业务配置下） | 维护网关编号、名称、IP 等基础信息 |

数据模型：实时监测默认使用模型编码 **`YSCJMX`（实时监测模型）**。组态图菜单可通过路由参数挂载不同模型（如电力 `ElectricityModel`、用水 `WaterSVGModel`）。

> **数据依赖**：实时值主要来自时序库（InfluxDB / `rtdb` 配置）。未部署 InfluxDB、MQTT 未连通或点位未绑定采集标签时，页面可能显示 `--` 或 `0`，后端一般仍可启动。

## 二、如何进入

1. 使用授权账号登录系统。
2. 在左侧菜单打开 **实时监测分析**（目录菜单，常见 path：`realtimemonitor`）。
3. 按需进入子菜单：
   - **实时监测**
   - **电力组态图监测** / **用水组态图监测**（以当前环境启用的菜单为准）
   - **网关状态监测**
4. 网关基础信息维护一般在 **业务配置 → 网关台账**。

菜单是否可见取决于角色权限；组件路径以系统菜单配置为准。

## 三、能源实时监测

页面路径示例：`realtimemonitor/realtimemonitor/realtimemonitor`  
对应接口：`GET /rtdb/realtimeTrend/list`、历史曲线 `GET /rtdb/realtimeTrend/chartByDay`。

### 3.1 界面布局

| 区域 | 说明 |
|------|------|
| 左侧树 | 实时监测模型（`YSCJMX`）下的用能单元节点树 |
| 顶部筛选 | **能源类型**下拉、搜索、重置、刷新 |
| 内容区 | 按能源类型分组的设备卡片；卡片内为各测点名称、实时值、采集时间 |

### 3.2 日常操作

1. 在左侧树点击目标节点（如总厂、某车间）。
2. 系统加载能源类型列表，默认选中第一项；也可手动切换能源类型后点 **搜索**。
3. 若该节点下有多台设备，在卡片上方设备标签中点击切换（选中设备高亮）。
4. 查看测点卡片：
   - **名称 + 单位**
   - **实时数值**（保留两位小数；无值时显示 `--`）
   - **采集时间**
5. 将鼠标悬停在测点上，提示「查看历史数据」；**单击测点**打开历史数据弹窗。

### 3.3 历史数据查询与导出

弹窗标题一般为「{测点名称}-历史数据查询」：

1. 选择 **日期**（默认当天）。
2. 点击 **搜索**，查看当日按时间点的曲线（横轴为时分）。
3. 需要留存报表时点击 **导出**（后端提供实时监测 Excel 导出能力，权限以账号为准）。

> 历史曲线接口按测点编码（`tagCode` / `indexCode`）与日期查询，需保证点位编码与采集侧一致。

### 3.4 使用建议

- 先确认左侧选中的是正确用能单元，再切换能源类型，避免看错范围。
- 数值长期为 `--` 时，优先检查该节点是否绑定采集点、Influx 是否有写入，而不是反复刷新页面。
- 支持浅色 / 深色主题；切换主题后列表会按当前主题重新加载展示。

## 四、组态图监测（SVG 绑定）

页面路径示例：`svg/equipmentfile/chartView`  
常见菜单：

| 菜单 | 路由参数示例 | 说明 |
|------|--------------|------|
| 电力组态图监测 | `modelCode=ElectricityModel` | 电力相关系统图 |
| 用水组态图监测 | `modelCode=WaterSVGModel` | 用水相关系统图（是否显示以菜单可见性为准） |

核心组件：`svg/components/configureView.vue`。

### 4.1 原理简述

1. 按节点加载已上传的 SVG 文件及「参数 ↔ 采集点」绑定关系（`GET /equipmentFile/configure/{nodeId}`）。
2. SVG 中带文字占位的元素，按绑定关系改写为对应测点编码（`tagCode`）。
3. 前端定时（约 **3 秒**）请求实时值，写回 SVG 中对应元素的文本。
4. 无数据时可能显示 `0`。

### 4.2 日常操作

1. 进入组态图监测菜单。
2. 在左侧树选择节点。
3. 右侧展示该节点系统图；图上数值会自动刷新。
4. 若显示「暂未上传」或空白，说明该节点尚未配置 SVG，请联系管理员按第五节完成配置。

### 4.3 使用注意

- 离开页面后定时刷新会停止，避免后台无效轮询。
- 组态图是否「活」取决于：SVG 已上传、文字占位与绑定表匹配、采集点有实时值。
- 不同能源品种可能使用不同模型编码，请从对应菜单进入，不要混用节点树。

## 五、组态图配置（管理员）

菜单示例：**组态图配置**（`svg/equipmentfile/index`），通常挂在基础配置类目录下。

### 5.1 配置步骤（概要）

1. 选择业务模型与节点。
2. **上传系统图**：支持 `svg` / `jpg` / `png` / `gif`（接口 `POST /equipmentFile/upload`）。
3. 将图与节点关联保存（`PUT /equipmentFile`）。
4. 配置参数与采集点映射并保存（`PUT /equipmentFile/setting/{nodeId}`）。
5. 回到组态图监测页，选择同一节点验证实时刷新。

### 5.2 SVG 绑定约定

- SVG 内用于展示数值的 `<text>` 内容应与配置中的 **参数名（param）** 对应。
- 每个参数绑定一个 **采集点编码（tag）**；运行时以该编码拉取实时值。
- 字典类型 `svgType`（组态图类型）用于区分图用途，配置时按现场规范选择。

> 仓库中另有 `realtimemonitor/topologymap` 等拓扑页样例；若菜单未启用或仍为演示节点，请以「组态图配置 + 组态图监测」主流程为准。

## 六、网关状态与网关台账

### 6.1 网关状态监测

菜单挂在「实时监测分析」下，组件路径常见为  
`businessconfiguration/gatewaystatus/gatewayStatus`。

**界面含义（示意）：**

- 横向展示「网关」侧编号/名称格点；
- 「计量器具」侧以圆点表示与网关的关联态势。

> **重要说明（社区版现状）**：当前页面数据多为前端静态示意，**未完整对接**网关实时在线接口。用于演示连通关系概念；生产环境请以 **网关台账**、现场 MQTT/采集日志及仪表通讯状态为准。后续版本若接入真实心跳/在线状态，操作步骤以更新后的界面为准。

### 6.2 网关台账（推荐维护入口）

菜单：**业务配置 → 网关台账**（`businessconfiguration/gatewayledger/gatewayLedger`）  
后端：`/gatewaySetting`（列表 / 新增 / 修改 / 删除 / 导出）。

可维护字段通常包括：

| 项 | 说明 |
|----|------|
| 网关编号 | 唯一，不可重复 |
| 网关名称 | 便于识别的安装位置或用途名 |
| IP 等连接信息 | 按现场网络填写 |
| 关联位置/总闸等 | 以台账表单为准 |

仪表档案中可关联网关主键，便于从设备追溯到采集入口。

### 6.3 运维建议

1. 新装网关先在台账登记编号与 IP。
2. 确认独立采集程序或内置 MQTT 订阅主题、Influx 写入正常（参见环境配置与架构文档）。
3. 实时监测无数据时：台账 → 仪表/点位绑定 → Broker/Influx 连通性，按链路逐段排查。

独立 MQTT 采集网关工程见：[zhitan-gateway](https://gitee.com/liulingling1993/zhitan-gateway)。

## 八、常见问题

### Q1：实时监测列表为空或全是 `--`？

检查：是否已选左侧节点；该节点下是否有设备与测点；能源类型是否匹配；InfluxDB（`RTDB_*`）是否可用；MQTT 主题与点位编码是否一致。

### Q2：切换节点后能源类型不对？

点击节点后会重新拉取能源类型并默认第一项。若需看其他品种，请在下拉框中切换后再点 **搜索**。

### Q3：组态图不刷新或全是 0？

检查：节点是否上传 SVG；参数与采集点是否绑定；SVG 文字占位是否与参数名一致；实时库是否有该 `tagCode` 的值。可打开浏览器开发者工具查看定时请求是否成功。

### Q4：无法上传系统图？

确认文件后缀为 svg/jpg/png/gif；账号具备上传权限；后端上传目录（`base.profile` / 部署卷）可写。

### Q5：网关状态页与台账里的网关对不上？

状态页当前多为示意数据；请以网关台账及现场采集状态为准，或以实施人员提供的定制监测页为准。

### Q6：历史曲线导出失败？

确认已选择测点与日期、账号具备导出权限，且当日有历史点。可先在弹窗中确认曲线有数据再导出。

### Q7：菜单打不开或 404？

核对系统菜单中的组件路径是否与当前前端版本一致（如 `realtimemonitor/realtimemonitor/realtimemonitor`、`svg/equipmentfile/chartView`）。路径错误时需管理员调整菜单配置。
