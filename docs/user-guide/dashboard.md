## 一、功能概述

「首页看板」是登录系统后的核心总览入口，用于快速掌握全厂用能、费用、储能运行与报警态势。

| 子看板 | 菜单名称 | 主要用途 |
|--------|----------|----------|
| 能耗总览 | 首页看板 / 默认首页 | 全厂能耗统计、趋势、占比、排名、尖峰平谷 |
| 成本看板 | 成本看板 | 能源成本与费用结构总览（可跳转成本趋势分析） |
| 储能看板 | 储能看板 | 储能运行状态与关键实时点位总览 |
| 报警看板 | 报警看板 | 报警态势总览（可结合报警分析 / 报警记录） |

> **说明**：能耗总览页面由前端 `views/index.vue` 提供，登录后默认进入 `/index`。成本 / 储能 / 报警子菜单由系统菜单配置挂载；若某环境菜单已启用但页面组件未部署，请联系管理员，或使用下文「相关入口」中的已有功能页。

## 二、如何进入

1. 使用授权账号登录系统（默认演示账号见快速开始文档，生产环境以管理员分配为准）。
2. 登录成功后默认进入 **首页看板（能耗总览）**。
3. 在左侧（或首页专用）导航中，可切换：
   - **首页看板**（能耗总览）
   - **成本看板**
   - **储能看板**
   - **报警看板**

支持浅色 / 深色主题切换；切换主题后首页图表会按当前主题重新渲染配色。

## 三、首页看板（能耗总览）

页面自上而下分为：顶部能耗卡片区、中部趋势与占比图、底部排名与尖峰平谷图。

数据模型编码固定为首页综合模型 `COMPREHENSIVE_CODE`（「首页看板模型」），一般无需用户手工选择模型。

### 3.1 全厂能耗统计（顶部卡片）

| 展示项 | 含义 |
|--------|------|
| 能源名称 + 单位 | 如电 (kWh)、水 (t) 等，来自能源基础数据 |
| 合计用量 `count` | 当前所选时间维度内的用量合计 |
| 同比 | 与去年同期对比的变化率（%）；箭头向上/向下表示升/降 |
| 环比 | 与上一周期对比的变化率（%）；日维度环比为「较昨日」，月/年维度为「较上月」 |

操作说明：

1. 卡片右上角可切换 **天 / 月 / 年**（字典 `period`：`DAY` / `MONTH` / `YEAR`）。
2. 若能源品种超过一屏展示数量，可点击 **查看更多**，在弹窗中浏览全部能源卡片。
3. 同比、环比为 **0** 时表示对比基数为空或持平，界面可能不显示箭头。

### 3.2 能耗趋势

- 位置：中部左侧图表「能耗趋势」。
- 含义：按时间轴展示各能源折标后的能耗走势，纵轴单位为 **tce（吨标煤）**。
- 时间轴粒度：
  - **天**：按小时
  - **月**：按天
  - **年**：按月
- 与顶部「全厂能耗统计」共用同一套时间切换；切换天/月/年后趋势图同步刷新。
- 可查看图例开关各能源系列；鼠标悬停查看具体时刻数值。

### 3.3 全厂能耗占比

- 位置：中部右侧图表「全厂能耗占比」。
- 含义：各能源品种折标煤（`tonCount`）在当期总折标煤中的占比，便于识别主导用能品种。
- 数据与顶部卡片同源；切换时间维度后同步更新。

### 3.4 厂区能耗排名

- 位置：下部左侧「厂区能耗排名 TOP N」。
- 含义：综合模型下 **一级子节点**（如车间 / 厂区）的能耗量排名，单位 **tce**。
- 该区域有独立的天/月/年切换，可单独切换而不影响顶部卡片（与顶部「全厂统计」控件相互独立）。
- 条形越长表示当期能耗越高；前三名在序号样式上通常有高亮区分。

### 3.5 尖峰平谷占比

- 位置：下部右侧「尖峰平谷占比」。
- 含义：当期用电在尖 / 峰 / 平 / 谷（以系统字典 `electricity_price` 配置为准）各时段的电量与占比。
- 同样支持独立的天/月/年切换。
- 用于判断负荷是否集中在高峰电价时段，辅助错峰用电分析。

### 3.6 页面数据刷新逻辑（便于理解）

| 操作 | 刷新内容 |
|------|----------|
| 顶部或趋势区切换天/月/年 | 全厂能耗统计、能耗趋势、全厂能耗占比 |
| 排名区切换天/月/年 | 仅厂区能耗排名 |
| 尖峰平谷区切换天/月/年 | 仅尖峰平谷占比 |
| 切换系统主题 | 上述图表按新主题重新渲染 |

对应后端接口（前缀以环境代理为准，如 `/dev-api`）：

| 功能 | 接口 |
|------|------|
| 全厂能耗统计 / 占比 | `GET /homepage/energyConsumptionSummation?timeType=` |
| 能耗趋势 | `GET /homepage/energyConsumptionTrend?timeType=` |
| 厂区排名 | `GET /homepage/energyConsumptionRanking?timeType=` |
| 尖峰平谷 | `GET /homepage/peakValley?timeType=` |

## 四、成本看板

### 4.1 定位

成本看板用于从 **费用** 视角查看能源成本构成与变化，和首页「用量 / 折标煤」视角互补。菜单挂载在「首页看板」下，路由名一般为 **成本看板**（`costIndex`）。

### 4.2 建议使用方式

1. 在首页看板菜单中点击 **成本看板**。
2. 若当前环境已部署成本看板组件，可直接查看成本汇总与结构图。
3. 若页面暂不可用，可使用已有成本分析功能：
   - 菜单：**成本趋势分析**（组件路径示例：`costAnalysis/cost-trend-analysis`）
   - 典型操作：选择期间（天/月/年）与时间 → 搜索 → 查看费用表格与费用/消耗量趋势图。

### 4.3 阅读要点

| 关注点 | 说明 |
|--------|------|
| 总费用 | 选定周期内能源费用合计（元） |
| 分品种费用 | 各能源类型对应的费用列 |
| 消耗量 vs 费用 | 用量升高不一定费用同比例升高，需结合电价时段与策略 |
| 模型 | 成本相关菜单常绑定成本模型（如 `NYCBMX`），以现场配置为准 |

更细的成本策略与电价关联操作，见后续用户手册「成本分析」（计划文档 `docs/user-guide/cost-analysis.md`）。

## 五、储能看板

### 5.1 定位

储能看板用于查看储能系统运行概况。菜单挂载在「首页看板」下（`esIndex`），关联模型编码一般为 **`ENERGY_STORAGE_KB`（储能看板）**。

### 5.2 实时点位配置（运维侧）

系统参数 / 字典中可配置储能看板关注的实时点位，例如参数键：

- `energy_storage_board_point`

常见点位语义（以现场字典与设备点表为准）：

| 点位示例 | 含义（示意） |
|----------|----------------|
| DeviceStatus | 设备运行状态 |
| BatteryCapacity | 电池容量 |
| SOC | 荷电状态 |
| SOH | 健康状态 |
| EnvironTemperature | 环境温度 |
| Humidity | 湿度 |
| SmokeDensity | 烟感浓度 |

### 5.3 使用建议

1. 从首页看板菜单进入 **储能看板**。
2. 确认侧栏或页面已带上模型参数 `modelCode=ENERGY_STORAGE_KB`（部分菜单在 query/queryParams 中自动带入）。
3. 关注 SOC/SOH、充放电状态与环境量是否异常；异常时结合报警看板或报警记录排查。

> 若当前分支未部署 `es/index` 页面组件，菜单可能无法打开，需管理员补齐前端组件或使用增强版/定制部署。更完整的储能操作说明见计划中的 `docs/user-guide/energy-storage.md`。

## 六、报警看板

### 6.1 定位

报警看板用于从首页视角快速掌握报警态势。菜单名称在库中为 **报警看板**（`alarmIndex`），挂在「首页看板」目录下。

### 6.2 推荐关联功能（社区版已具备）

即使专用「报警看板」组件未部署，也可使用实时监测下的报警功能完成日常工作：

| 功能 | 菜单/页面 | 用途 |
|------|-----------|------|
| 报警分析 | `alarmmanage/measuremen/measuremen` | 指标数、本年/本月报警次数，报警类型占比、能源类型占比、报警次数趋势 |
| 报警记录 | `alarmmanage/alarmrecord/alarmRecord` | 按节点、时间、报警类别、指标名称查询明细 |

顶部导航铃铛等入口也可能跳转到报警分析页（如带 `modelCode=BJGL`）。

### 6.3 报警分析常用操作

1. 左侧选择用能单元节点。
2. 选择期间（天/月/年）与时间，点击 **搜索**。
3. 查看：
   - 本用能单元指标个数、本年/本月报警次数摘要
   - **报警类型占比**、**能源类型占比** 饼/环图
   - **报警次数** 趋势图
4. 需要明细时，进入 **报警记录**：设置本级/含下级、时间范围、报警类别、指标名称后查询。

报警规则阈值的配置与维护，见后续用户手册「告警管理」（`docs/user-guide/alarm.md`）。

## 七、时间维度说明

首页及相关看板大量使用字典 **`period`**：

| 标签 | 值 | 典型数据粒度（能耗类） |
|------|-----|------------------------|
| 天 | `DAY` | 按小时汇总/展示 |
| 月 | `MONTH` | 按天汇总/展示 |
| 年 | `YEAR` | 按月汇总/展示 |

同比 / 环比口径（首页能耗统计）：

| 维度 | 同比 | 环比 |
|------|------|------|
| 天 | 相对去年同日所在时段 | 相对昨天 |
| 月 | 相对去年同月 | 相对上个月 |
| 年 | 相对去年 | 相对上年（实现上按偏移月份计算，以页面展示为准） |

## 八、常见问题

### Q1：首页卡片全部为 0？

检查：PostgreSQL 中能耗数据是否已清洗入库；模型 `COMPREHENSIVE_CODE` 是否配置节点与点位；点位是否绑定能源类型；Influx / 采集链路是否正常（影响实时，历史统计依赖关系库数据）。

### Q2：尖峰平谷图无数据？

检查字典 `electricity_price` 是否配置尖峰平谷类型；模型节点下是否有电相关指标；尖峰平谷统计表是否有对应时段数据。

### Q3：厂区排名为空？

首页排名取综合模型根节点下的 **直接子节点**。若未建子节点或子节点无能耗数据，列表为空。

### Q4：同比环比箭头颜色如何理解？

界面用绝对值显示百分比，并用上/下箭头表示方向：上升、下降。具体业务上「升高是否异常」需结合生产计划判断，不单看箭头颜色。

### Q5：成本 / 储能 / 报警子菜单打不开？

多为菜单已配置但前端组件路径（如 `costAnalysis/index`、`es/index`、`alarmmanage/alarmIndex`）未随当前版本发布。请联系实施人员核对菜单组件路径，或改用本文「相关入口」中的已有页面。

### Q6：切换主题后图表空白？

一般会自动重绘；若仍空白可刷新浏览器，或重新切换一次天/月/年触发查询。
