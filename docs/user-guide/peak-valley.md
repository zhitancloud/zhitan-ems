## 一、功能概述

尖峰平谷功能分为「先配置电价时段」与「再看用量/电费结构」两部分。

| 功能模块 | 典型菜单名称 | 主要用途 |
|----------|--------------|----------|
| 尖峰平谷配置 | 尖峰平谷配置 | 维护电价生效日期段，以及每日尖/峰/平/谷（等）时段与单价 |
| 峰平谷时段统计 | 峰平谷时段统计 | 按**月**查看节点尖峰平谷电量、电费、占比与日趋势 |
| 峰平谷分时统计 | 峰平谷分时统计 | 按**日**查看各小时尖峰平谷电量/电费、占比饼图，支持导出 |

首页看板中的「尖峰平谷占比」为总览入口，详细操作见 [用户手册 - 首页看板](./dashboard.md)；本手册覆盖配置与分析子页。

> **说明**：分析页读取的是已入库的尖峰平谷统计（表 `energy_used_electricity` 等），不是实时库瞬时值。未配置时段电价、未启用尖峰平谷计算或未完成聚合时，图与表可能为 0 或空。

---

## 二、如何进入

1. 使用授权账号登录系统。
2. 按角色打开：
   - **配置（管理员/实施）**：模型配置相关菜单 → **尖峰平谷配置**
   - **分析（日常）**：**能效分析 → 尖峰平谷分析 → 峰平谷时段统计 / 峰平谷分时统计**
3. 分析子菜单路由参数通常带 `{"modelCode":"JFPGMX"}`；菜单是否可见取决于权限与显示状态。

## 三、尖峰平谷配置（生效期与时段电价）

页面路径示例：`modelconfiguration/setpeakvalley/setPeakValley`  
接口前缀：

| 用途 | 方法 | 路径 |
|------|------|------|
| 生效期列表/增删改 | GET/POST/PUT/DELETE | `/electricitypricedate`、`/electricitypricedate/list`、`/electricitypricedate/{id}` |
| 时段电价列表 | GET | `/electricityprice/list?parentId=...` |
| 时段电价整表保存 | PUT | `/electricityprice/save` |

### 3.1 生效日期段（父表）

列表字段：生效开始日期、生效结束日期、备注、创建时间。

操作：

1. 可用 **备注** 搜索，点 **搜索** / **重置**。
2. 点 **时段配置** 新增一条生效日期范围（日期区间 + 备注）。
3. 行内 **编辑** 修改日期或备注；**删除** 删除该生效期（请先确认其下电价明细是否仍需要）。

> **校验**：不同生效期的日期范围**不能相交**。系统提示「时间段存在交集，无法保存」时，请调整开始/结束日期后再保存。

### 3.2 时段电价明细（子表）

1. 在某条生效期行点击 **电价配置**。
2. 弹窗中为该生效期配置多行：

| 字段 | 说明 |
|------|------|
| 类别名称 | 字典 `electricity_price`（尖/峰/平/谷等，以后端字典为准） |
| 时段电价 | 单价，精度一般两位小数，≥ 0 |
| 开始时间 / 结束时间 | 半小时步进（`00:00`～`24:00`），结束须晚于开始（跨日到 `00:00` 的收尾段按业务配置） |
| 备注 | 可选 |

3. 可用行内 **新增** / **删除** 增减时段行。
4. 点确定保存：后端会**整表替换**该 `parentId` 下旧明细。

> **保存校验（后端）**：
> - 价格明细不能为空  
> - 各时段**不能时间重叠**（提示「时间段存在重叠，请检查！」）  
> - 各时段须**首尾相连并覆盖完整 24 小时**（提示「时间没有覆盖24小时」）

配置完成且统计任务按配置切分电量后，分析页才能看到正确的尖峰平谷结构。

## 四、峰平谷时段统计（按月）

页面路径示例：`peakvalley/period/period`  
接口：`GET /peakValley/segmentAnalysis/day`  
默认模型：**`JFPGMX`（尖峰平谷模型）**  
前端固定 `timeType: MONTH`（按所选月份汇总日数据）。

### 4.1 界面结构

- **左侧**：节点树，点击节点切换分析对象。
- **右侧筛选**：月份（`YYYY-MM`）、**搜索** / **重置**。
- **顶部卡片**：合计，以及尖 / 峰 / 平 / 谷（等）时段的耗电量、耗电占比、用电费用、费用占比。
- **尖峰平谷电量图**：按日展示尖/峰/平/谷电量趋势。
- **尖峰平谷电费图**：按日展示对应电费趋势。

### 4.2 日常操作

1. 打开 **尖峰平谷分析 → 峰平谷时段统计**。
2. 在左侧树选择节点（会默认当前月并查询）。
3. 切换月份后点 **搜索**。
4. 先看顶部卡片把握当月结构，再看电量图 / 电费图定位偏高日期。

卡片与图表均来自接口返回的 `totalVO`、`powerConsumptionList`、`costList`；无数据时多为 0。

## 五、峰平谷分时统计（按日）

页面路径示例：`peakvalley/timeSharing/timeSharing`  
接口：`GET /peakValley/segmentAnalysis/hour`  
导出：`POST /peakValley/segmentAnalysis/hour/export`  
默认模型：**`JFPGMX`**  
前端固定 `timeType: DAY`（按所选日展开小时）。

### 5.1 界面结构

- **左侧**：节点树。
- **右侧筛选**：日期（`YYYY-MM-DD`）、**搜索** / **重置** / **导出**。
- **峰平谷电量图**：当日各小时尖/峰/平/谷电量折线（或组合图）。
- **峰平谷占比图**：当日尖/峰/平/谷电量占比饼图。
- **峰平谷分时统计表**：0～23 时，分列尖/峰/平/谷的耗电量(kWh)、电费(元)，以及合计总电量/总电费；表格带合计行。

### 5.2 日常操作

1. 打开 **尖峰平谷分析 → 峰平谷分时统计**。
2. 选择节点与日期，点 **搜索**。
3. 用占比图看结构，用电量图与表定位高峰小时。
4. 需要留存时点 **导出**（按当前节点与日期导出分时明细）。

## 六、相关模型与字典

| 编码 / 字典 | 名称 | 使用场景 |
|-------------|------|----------|
| `JFPGMX` | 尖峰平谷模型 | 时段统计、分时统计菜单默认 `modelCode` |
| `electricity_price` | 尖峰平谷配置（类别） | 电价配置「类别名称」下拉 |
| `spikes_and_valleys` | 尖峰平谷配置 | 其它成本/策略场景中的尖峰平谷字典 |
| `period` | 期间 | 系统其它按天/月/年筛选页（本分析页时段/分时已固定 MONTH/DAY） |

模型节点在 **模型配置** 中维护；统计指标需开启尖峰平谷计算（如指标/存盘规则中的「是否计算尖峰平谷」）后，聚合才会写入尖峰平谷结果。

用电类型与后端枚举常见对应：`SHARP`（尖）、`PEAK`（峰）、`FLAT`（平）、`VALLEY`（谷）；部分实现会将未识别类型计入谷侧，现场以配置与字典为准。

## 七、推荐配置与分析流程

1. **建模型节点**：确认 `JFPGMX` 下节点与用电相关指标已绑定，并开启尖峰平谷计算。
2. **配生效期**：在尖峰平谷配置中新增不重叠的日期段（可按季节/政策切换）。
3. **配 24 小时时段电价**：每段类别 + 单价 + 起止时间，无重叠且覆盖全天，保存成功。
4. **等聚合**：待日/小时尖峰平谷数据入库（实施侧任务或清洗流程）。
5. **月看结构**：用时段统计看当月尖峰平谷电量/电费占比与日趋势。
6. **日看明细**：用分时统计下钻到小时，必要时导出。
7. **对照首页**：全厂尖峰平谷占比见首页看板。

## 八、常见问题

### Q1：保存电价提示「时间没有覆盖24小时」或「存在重叠」？

检查各行开始/结束是否首尾相接（如 `06:00` 接下一段 `06:00`）、是否有交叉，以及是否从 `00:00` 覆盖到次日 `00:00`（或业务约定的 24 小时闭环）。半小时步进下不要留空档。

### Q2：保存生效期提示「时间段存在交集」？

与已有生效期的日期区间重叠。调整开始/结束日期，使各段不相交（可相邻）。

### Q3：分析页全是 0 或图表空白？

检查：是否选了 `JFPGMX` 下有指标的节点；该月/日是否有聚合数据；对应日期是否落在已配置的电价生效期内；账号是否有接口权限。

### Q4：时段统计与分时统计数字对不上？

时段统计按**整月按日**汇总；分时统计按**单日按小时**。对比时请用同一节点，且分时日期属于该月。

### Q5：电价改了，历史图没变？

已入库的历史尖峰平谷统计一般不会自动按新电价重算。新配置主要影响后续聚合；历史是否重算取决于实施策略。

### Q6：导出失败？

确认已选节点与日期、具备导出权限，且浏览器未拦截下载；可先确认表格有数据再导出。

### Q7：菜单 404？

核对组件路径：`modelconfiguration/setpeakvalley/setPeakValley`、`peakvalley/period/period`、`peakvalley/timeSharing/timeSharing`，以及菜单 `modelCode` 是否为 `JFPGMX`。
