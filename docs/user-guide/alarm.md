## 一、功能概述

「报警中心管理」用于配置「什么条件算报警」、查看「报警发生得怎样」、追溯「具体哪次超限」。

| 子功能 | 典型菜单名称 | 主要用途 |
|--------|--------------|----------|
| 报警限值类型 | 报警限值类型 | 维护上限/下限等类型编码、比较符、色号、预警/报警类别 |
| 预报警管理 | 预报警管理 | 按节点为采集点/统计指标设置时段限值，并启停规则 |
| 报警分析 | 报警分析 | 按节点汇总指标数、年/月报警次数及类型/能源占比、次数趋势 |
| 报警记录 | 报警记录 | 按本级或含下级查询历史报警明细 |
| 能耗报警 | 能耗报警 | 菜单存在但社区版默认可能隐藏，以现场启用情况为准 |

默认业务模型编码：**`BJGL`（报警中心管理）**。多数子菜单路由参数带 `{"modelCode":"BJGL"}`。

> **说明**：报警产生依赖采集实时值与已启用的预报警限值。仅配置限值类型而不配置节点阈值、或不启停规则，不会产生有效报警记录。

## 二、如何进入

1. 使用授权账号登录系统。
2. 在左侧菜单打开 **报警中心管理**（目录 path 常见为 `alarmmanage`）。
3. 按角色进入子菜单：
   - **报警分析** / **报警记录**（日常值班常用）
   - **报警限值类型** / **预报警管理**（规则配置，需相应权限）
4. 首页铃铛或首页看板中的报警入口，也可能跳转到报警分析（带 `modelCode=BJGL`）。

菜单是否可见取决于角色权限与菜单「显示」状态。

## 三、报警限值类型

页面路径示例：`businessconfiguration/alarmmaintenance/alarmMaintenance`  
权限标识示例：`basicsetting:limitType:list`  
接口前缀：`/alarm/limit`

### 3.1 用途

定义限值「类型模板」，供预报警弹窗选择，例如：

| 字段 | 含义 |
|------|------|
| 限值类型名称 | 如上限、下限、上上限 |
| 限值类型编号 | 唯一编码，不可与其它类型重复 |
| 报警限制类型 | 字典 `alarm_type`（如预警 / 报警） |
| 色号 | 界面展示颜色 |
| 比较运算符 | `>` / `>=` / `<` / `<=` / `=` |

### 3.2 日常操作

1. 进入 **报警限值类型**。
2. 可按「限值类型名称」搜索。
3. 点击 **新增**：填写名称、编号、类型、色号、比较符后保存。
4. 行内 **修改** / **删除** 维护已有类型。
5. 编号重复时系统会提示「限制值类型编号不能重复」，请更换编号。

> 删除前请确认预报警规则未再引用该类型编码，避免规则失效或展示异常。

## 四、预报警管理（规则与阈值）

页面路径示例：`businessconfiguration/prealarmmanage/prealarmmanage`  
模型：`BJGL`  
相关接口：`/system/alarmitem/*`（启停、限值弹窗保存等）

### 4.1 界面结构

| 区域 | 说明 |
|------|------|
| 左侧树 | 报警模型节点（用能单元） |
| 页签 | **采集点管理** / **统计指标管理** |
| 内容区 | 当前节点下的点位/指标列表及报警设置入口 |

### 4.2 配置阈值（常用）

1. 左侧选择节点（如总厂、车间）。
2. 选择 **采集点管理** 或 **统计指标管理**。
3. 在列表中找到目标测点/指标，打开报警设置弹窗。
4. 选择 **报警级别**（字典 `alarm_level`）。
5. 在表格中按 **时段**（字典 `warn_time_slot`，如实时 `LIVE`）与 **限值类型** 填写 **限值**。
6. 点击 **确定** 保存。空限值行会被忽略；若全部清空，等价于清除该点已有限值配置。

保存后系统会生成形如 `点位ID:时段:限值类型` 的报警编码（`alarmCode`），用于关联历史报警。

### 4.3 规则启停

- 支持对选中项批量 **启动 / 停止**（启停状态：`1` 启动，`2` 停止）。
- 停止后该点规则不再生效（具体以现场判定服务是否读取启停标志为准）。
- 无权限账号无法操作启停或修改限值。

### 4.4 使用建议

- 先维护好 **报警限值类型**，再在预报警管理中填具体数值。
- 上限/下限成对配置时，注意下限应小于上限，避免逻辑矛盾。
- 修改阈值后，新报警按新限值判定；已产生的历史记录不会被回溯改写。

## 五、报警分析

页面路径示例：`alarmmanage/measuremen/measuremen`  
接口示例：`/alarmAnalysis/getByNodeId`、`/alarmAnalysis/getCountInfo`

### 5.1 界面内容

| 区域 | 说明 |
|------|------|
| 摘要条 | 本用能单元指标个数、本年度报警次数、本月报警次数 |
| 报警类型占比 | 按报警类型分布的图表 |
| 能源类型占比 | 按能源品种分布的图表 |
| 报警次数 | 选定期间内的次数趋势图 |

### 5.2 操作步骤

1. 左侧选择用能单元节点。
2. 选择 **期间**（天 / 月 / 年，字典 `period`）与对应 **时间**。
3. 点击 **搜索**（切换节点时通常会自动按当前期间刷新）。
4. 查看摘要与三张图；需要明细时转到 **报警记录**。

## 六、报警记录与导出

页面路径示例：`alarmmanage/alarmrecord/alarmRecord`  
接口示例：`GET /energyAlarm/historicalAlarm/list`  
导出：`GET /energyAlarm/historicalAlarm/export`（需导出权限）

### 6.1 查询条件

| 条件 | 说明 |
|------|------|
| 本级 / 包含下级 | `B` 仅当前节点点位；`ALL` 含下级地址展开的指标 |
| 时间选择 | 起止日期时间；默认当天 00:00:00～23:59:59 |
| 报警类别 | 字典 `alarm_record_category`（如采集点 / 统计指标） |
| 指标名称 | 模糊过滤 |

### 6.2 结果列（常见）

- 用能单元、指标名称、报警类别、能源类型
- 预设值（限值）、报警值、报警时间

### 6.3 操作步骤

1. 左侧点选节点。
2. 设置本级/含下级、时间、类别、指标名称。
3. 点击 **搜索**；底部分页浏览。
4. 需要报表时，在具备权限的前提下使用导出能力（接口导出 Excel；若页面未放导出按钮，可由管理员开放或通过接口工具导出）。

未传时间时，后端分页查询默认按 **当天** 起止时间处理。

|----------|------|

## 八、推荐配置流程

```text
1. 确认 BJGL 模型节点与点位/指标已绑定
        ↓
2. 维护报警限值类型（编码、比较符、色号）
        ↓
3. 预报警管理：按节点配置采集点/统计指标限值并启动
        ↓
4. 确认采集实时值正常（实时监测 / Influx）
        ↓
5. 用报警分析看态势，用报警记录查明细与导出
```

## 九、常见问题

### Q1：报警分析次数一直是 0？

检查：节点是否选对；期间与时间是否覆盖有数据区间；预报警是否已配置并 **启动**；现场是否确实发生过超限；历史表 `alarm_history` 是否有写入。

### Q2：报警记录查不到数据？

检查：本级/含下级是否选错（本级无点位时结果为空）；时间范围；报警类别与指标名称过滤是否过严；节点下是否绑定了指标。

### Q3：保存限值提示编号重复？

发生在 **报警限值类型** 新增/修改时，换一个未占用的限值类型编号即可。

### Q4：预报警弹窗保存后仍无报警？

确认限值非空且已启动；比较运算符与实际值方向是否匹配（如上限应用 `>`/`>=`）；采集值是否进入系统；判定任务/服务是否在运行（以现场部署为准）。

### Q5：无权限操作？

限值类型、预报警启停/改限值、历史导出等接口均有权限注解。请联系管理员分配 `basicsetting:limitType:*`、`system:alarmitem:*`、`energyAlarm:historicalAlarm:*` 等权限。

### Q6：能耗报警菜单打不开？

社区版菜单中「能耗报警」可能为隐藏状态。需要时由管理员在系统菜单中改为显示，或使用报警分析 + 报警记录完成日常工作。
