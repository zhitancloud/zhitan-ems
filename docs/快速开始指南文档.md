# 快速开始指南

> 本文面向首次接触智碳能源管理系统的开发者，帮助你在 5 分钟内完成环境搭建并启动项目。

---

## 一、环境要求

在开始之前，请确保你的开发环境已安装以下软件：

| 软件 | 最低版本 | 推荐版本 | 说明 |
|------|---------|---------|------|
| JDK | 1.8+ | 1.8 (JDK 8) | 后端编译运行环境，**必须使用 JDK 8** |
| Maven | 3.0+ | 3.6+ | 后端依赖管理与构建工具 |
| PostgreSQL | 14+ | 14+ | 主数据库 |
| Redis | 5.0+ | 6.0+ | 缓存中间件 |
| InfluxDB | 2.7+ | 2.7+ | 时序数据库，用于存储实时采集数据 |
| Node.js | 14.0+ | 16+ | 前端运行环境 |
| Yarn | 1.22+ | 1.22+ | 前端包管理器（推荐） |

### 版本验证

打开终端，执行以下命令确认版本：

```bash
java -version       # 应输出 java version "1.8.x"
mvn -version        # 应输出 Apache Maven 3.x
psql --version      # 应输出 psql (PostgreSQL) 14.x
redis-cli --version # 应输出 redis-cli 5.x 或 6.x
node -v             # 应输出 v14.x 或更高
yarn -v             # 应输出 1.22.x
```

## 三、初始化基础设施

项目依赖 PostgreSQL、Redis、InfluxDB 三个服务。你可以使用 Docker 快速启动，也可以本地安装。

### 方式一：Docker 快速启动依赖服务（推荐）

如果已安装 Docker，可以一键启动所有依赖服务：

```bash
# 启动 PostgreSQL
docker run -d \
  --name zhitan-postgres \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_DB=zhitan_ems \
  -p 5432:5432 \
  postgres:14

# 启动 Redis
docker run -d \
  --name zhitan-redis \
  -p 6379:6379 \
  redis:6

# 启动 InfluxDB
docker run -d \
  --name zhitan-influxdb \
  -p 8086:8086 \
  influxdb:2.7
```

> **提示**：如果使用 Windows PowerShell，需要将 `\` 换行符替换为反引号 `` ` `` 或写成单行命令。

**PowerShell 版本**：

```powershell
# 启动 PostgreSQL
docker run -d --name zhitan-postgres -e POSTGRES_USER=postgres -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=zhitan_ems -p 5432:5432 postgres:14

# 启动 Redis
docker run -d --name zhitan-redis -p 6379:6379 redis:6

# 启动 InfluxDB
docker run -d --name zhitan-influxdb -p 8086:8086 influxdb:2.7
```

### 方式二：本地安装

如果选择本地安装，请分别安装 PostgreSQL 14+、Redis 5.0+、InfluxDB 2.7+，并确保以下端口未被占用：

| 服务 | 默认端口 |
|------|---------|
| PostgreSQL | 5432 |
| Redis | 6379 |
| InfluxDB | 8086 |
| 后端应用 | 8080 |
| 前端开发服务器 | 80 |

## 四、初始化数据库

1. 使用 `psql` 或数据库管理工具（如 Navicat、DBeaver）连接到 PostgreSQL。

2. 创建数据库（如果 Docker 启动时未自动创建）：

```sql
CREATE DATABASE zhitan_ems ENCODING 'UTF8';
```

3. 导入初始化脚本：

```bash
# 使用 psql 命令行导入
psql -h localhost -U postgres -d zhitan_ems -f sql/public-v3.sql
```

或在 Navicat / DBeaver 中打开 `sql/public-v3.sql` 文件并执行。

## 五、启动后端

### 5.1 修改配置

编辑 `zhitan-admin/src/main/resources/application-dev.yml`，根据实际环境修改以下配置：

```yaml
spring:
  datasource:
    druid:
      master:
        # 数据库连接地址（按实际情况修改）
        url: jdbc:postgresql://localhost:5432/zhitan_ems
        username: postgres
        password: postgres
```

编辑 `zhitan-admin/src/main/resources/application.yml`，确认以下配置：

```yaml
# Redis 配置（默认无密码）
spring:
  redis:
    host: localhost
    port: 6379
    password:           # 如设置了密码请在此填写

# InfluxDB 配置
rtdb:
  host: http://127.0.0.1:8086
  token: ==             # InfluxDB API Token（按实际修改）
  org: org              # InfluxDB 组织名称
  bucket: bucket        # InfluxDB 存储桶名称

# MQTT 配置（可选，不影响基本功能启动）
mqtt:
  host: tcp://127.0.0.1:1883
```

### 5.2 编译项目

在项目根目录执行 Maven 编译：

```bash
# 首次编译（安装所有模块到本地仓库）
mvn clean install -Dmaven.test.skip=true
```

> **说明**：`-Dmaven.test.skip=true` 跳过测试以加快编译速度。首次编译需要下载依赖，可能需要几分钟。

### 5.3 启动应用

```bash
# 方式一：使用 Maven 插件启动（推荐开发时使用）
cd zhitan-admin
mvn spring-boot:run

# 方式二：使用 Java 命令启动（打包后）
cd zhitan-admin/target
java -jar zhitan-admin.jar
```

启动成功后，终端会显示如下信息：


## 六、启动前端

### 6.1 安装依赖

```bash
cd zhitan-vue
yarn install
```

> **提示**：如果 `yarn install` 下载速度慢，可以先配置国内镜像：
> ```bash
> yarn config set registry https://registry.npmmirror.com
> ```

### 6.2 开发模式启动

```bash
yarn dev
```

启动后会自动打开浏览器访问 `http://localhost`。

前端开发服务器已配置代理，会自动将 `/dev-api` 开头的请求转发到后端 `http://localhost:8080`。

### 6.3 生产构建

如果需要打包部署：

```bash
# 构建生产版本
yarn build

# 构建预发布版本
yarn build:stage
```

构建产物输出在 `dist/` 目录，可部署到 Nginx 或其他 Web 服务器。

## 八、常见问题

### Q1：后端启动报数据库连接错误

请检查：
1. PostgreSQL 是否已启动：`pg_isready -h localhost -p 5432`
2. 数据库 `zhitan_ems` 是否已创建
3. `application-dev.yml` 中的用户名密码是否正确

### Q2：Redis 连接失败

请检查：
1. Redis 是否已启动：`redis-cli ping`（应返回 `PONG`）
2. 如果 Redis 设置了密码，需要在 `application.yml` 中配置 `spring.redis.password`

### Q3：前端页面空白或接口 404

请检查：
1. 后端是否已启动并正常运行在 `8080` 端口
2. 前端代理配置是否正确（`zhitan-vue/vite.config.js` 中 `/dev-api` 代理到 `http://localhost:8080`）

### Q4：Maven 编译失败提示找不到 rt.jar

JDK 9+ 移除了 `rt.jar`，本项目**必须使用 JDK 8** 编译。请确认 `java -version` 输出为 `1.8.x`。

### Q5：InfluxDB 连接失败

InfluxDB 主要影响实时数据监测功能，不影响系统登录和基础功能使用。如需完整功能：
1. 确认 InfluxDB 已启动并运行在 `8086` 端口
2. 在 `application.yml` 中正确配置 `rtdb` 相关参数

### Q6：前端 yarn install 报错

1. 确认 Node.js 版本 ≥ 14：`node -v`
2. 尝试清除缓存后重新安装：
   ```bash
   yarn cache clean
   rm -rf node_modules
   yarn install
   ```
