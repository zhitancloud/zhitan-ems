# 测试文档目录

本目录存放 **UPDATE_PLAN 奇数日（单元测试日）** 同步输出的测试说明文档。

| 约定 | 说明 |
|------|------|
| 模板 | [`_TEMPLATE.md`](./_TEMPLATE.md) |
| 命名 | 与模块对应，如 `peakvalley.md`、`keyequipment.md`、`costmanagement.md` |
| 规则 | 测试日 = 测试代码 + 本目录文档 + 更新 `UPDATE_PLAN` |

历史 Day 1–25 的测试以代码为主，测试文档自约定生效后的下一次测试日起编写；需要回补时按模板补写即可。
